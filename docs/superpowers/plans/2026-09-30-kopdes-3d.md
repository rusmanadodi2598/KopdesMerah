# Kopdes 3D: Maju Desaku — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membangun game 3D browser "Kopdes 3D: Maju Desaku" yang bisa dimainkan — jaga toko koperasi + sub-misi keliling desa + leveling gedung Kopdes.

**Architecture:** Modul ES murni tanpa build step. Logika game (stok, kasir, misi, level, save) dipisah sebagai modul murni tanpa dependensi Three.js agar bisa diuji dengan `node:test`. Kode rendering Three.js hanya membaca/menulis state dari modul logika.

**Tech Stack:** Three.js 0.160.0 (di-vendor sebagai `vendor/three.module.js`, tanpa CDN), HTML/CSS/JS + ES modules, `node:test` untuk unit test. Tanpa framework, tanpa build tool.

**Spec:** `docs/superpowers/specs/2026-09-30-kopdes-3d-design.md`

## Global Constraints

- Tanpa build step: murni HTML/CSS/JS + ES modules; `node --check` dan `node --test` adalah satu-satunya tooling.
- Three.js versi 0.160.0, file `vendor/three.module.js` di dalam repo (tidak boleh CDN).
- Semua teks UI berbahasa Indonesia.
- Save/load hanya via `localStorage`, key `kopdes3d_save_v1`.
- Target performa: 30fps di HP menengah — low-poly, pohon & barang rak memakai `InstancedMesh`.
- Angka dari spec: 8 barang, 5 misi, 3 level Kopdes, 5–6 rumah warga, 1 desa.
- Harga ekonomi sederhana: harga jual tetap per hari (tanpa fluktuasi pasar) untuk MVP.

## Review Focus

1. Spam klik tombol bayar di kasir → pemain ke-charge 2x untuk 1 transaksi. Harapan: 1 ID transaksi hanya diproses 1x. → Test di Task 5.
2. Stok 0 tapi barang tetap terjual → stok negatif. Harapan: penjualan ditolak saat stok 0. → Test di Task 5.
3. Data `localStorage` korup (JSON rusak / diedit manual) → game crash saat load. Harapan: kembali ke default dengan aman. → Test di Task 9.
4. Toko tutup saat pembeli masih antre → NPC stuck selamanya. Harapan: antrean bubar, NPC pulang. → Test di Task 4.
5. Misi diselesaikan tanpa membawa barang syarat → reward gratis. Harapan: penyelesaian ditolak dengan pesan jelas. → Test di Task 7.

```js
  const loop = createLoop({ update: () => calls++, render: () => {}, raf: (cb) => callbacks.push(cb) });

  assert.equal(calls, 2); assert.equal(loop.tickCount(), 2);
});
```
